# 海洋视频与来源恢复

相关兴趣可从 [NOAA Ocean Today 海洋生物目录](https://oceantoday.noaa.gov/marine-life.html) 随机选最多三个未分析条目，只接受官方页面列出的 MP4 下载，优先低清版本。初始主机为 oceantoday.noaa.gov；实际官方重定向到 cdn.oceanservice.noaa.gov/oceantodayprod/media/。每跳都验证白名单、公网地址及 TLS。

沿用20MB、120秒、四帧、前60秒音轨、30天去重、失败冷却、每日探索和分享上限。没有账户、评论或额外循环；科普档案发布时间未知时明确说明。`/platform noaa 主题或官方视频页` 可手动请求，仍需 `/watch on`；`/platforms off` 关闭自主平台尝试。

普通研究默认不提取网页链接。视频目录解析时才请求最多200个链接与限长标题，候选仍逐一验证。视频表达复用普通聊天的小鲸鱼语气，保留必要的不确定性；完整方法范围留在报告，短分享保留原链接及抽样提示。

公开订阅先读取目录与未读正文。第一篇失效可尝试下一篇，成功取得一篇后停止；包括失败在内最多四次来源读取尝试，每次仍有下载、时间、重定向和地址限制。自主探索取得未读正文后跳过额外搜索模型调用，否则再搜索其他来源。只有目录时不调用综合模型、不推荐，也不把访问失败当作内容偏好。

保留条目发布日期，未读不等于近期发布。新安装默认加入 [NOAA 海洋知识源](https://oceanservice.noaa.gov/rss.html)；现有安装可用 `/feeds add 海洋动物 https://oceanservice.noaa.gov/rss/oceanfacts.xml` 添加，不会重置已关闭的开关或自动恢复被移除的源。

所有来源读取失败时，在私人报告目录保留失败清单，不生成伪成果。自动探索总时限为540秒，为600秒任务租约预留退出时间；更早发生的取消和额度保护仍优先。不能保证所有网站或视频都可达。
