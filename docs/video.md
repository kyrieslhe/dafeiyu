# 短视频采样理解（开发预览）

在绑定后接收微信已下载的视频，复制到本机受限目录后入队后台任务。原始附件保留，不把聊天阻塞在解码过程。

安装：`python3 scripts/setup_video.py`。从固定Python3.12.16摘要和经过PyPI SHA256校验的PyAV19.0.2 wheel构建本机镜像，不在构建或运行时安装未锁定依赖。运行采用非root、只读根、无网络、cap-drop ALL、512MB、2CPU及30秒解码时限。

支持20MB以内、120秒以内的MP4/MOV/WebM，最大4096边长及16MP。提取最多四张带真实时间点的静态画面，交给现有Codex图像输入理解；音轨可抽取最多前60秒并在离线ASR可用时转写。报告明确采样范围，不声称完整连续观看。媒体和抽帧保留七天，原始媒体不包含在数据库/报告备份内。

已实测：原创三秒纯蓝MP4在无网络容器中得到0/1/2/2.9秒四帧，真实Codex任务正确描述蓝色且说明没有音轨。七项视频检查启用真实 Docker 后全通过，包括原创 AAC 音轨转为 16kHz 单声道 PCM 的实际检查；CI 会重建固定镜像并执行真实解码。另已实际完成原创中文 TTS → MP4/AAC → 隔离抽取 PCM → 离线 ASR，识别出预期“大肥鱼”文字；这不是微信传输证据。真实微信视频入站仍待验证，因此本阶段仍为开发预览。

本功能不下载B站/其他网站视频，不登录平台，不发布评论。公开网页浏览和用户提供短片是不同能力。
