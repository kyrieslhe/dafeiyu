# 视频平台的匿名公开阅读

按维护者最新要求，不注册或登录账号，不建立个人浏览器档案，不复制 Cookie。B站和抖音只接受公开视频条目：B站 `www.bilibili.com/video/BV...`，抖音 `www.douyin.com/video/...` 或官方精选公开条目 `jingxuan.douyin.com/m/video/...`；不进入账号、私信或管理页面。

```text
大肥鱼 /platform bilibili 海洋里一个有趣的小问题
大肥鱼 /platform douyin 一个公开视频链接或主题
大肥鱼 /platform youtube 动物、音乐、旅行或其他兴趣
大肥鱼 /platform youtube https://www.youtube.com/watch?v=公开视频编号
大肥鱼 /platforms
大肥鱼 /platforms off
```

也可自然说“去 YouTube 找找……”“去油管看看……”。YouTube 可按任意公开兴趣搜索，或接受 watch、shorts、youtu.be 地址；删除跟踪参数，不接受账号、登录和管理页。当前读取公开标题、作者与简介，不获取字幕或播放画面，不把作者文案当成自己的观看经历。最多读取一个候选页，4MB / 15秒上限；不跟随登录重定向，不调用播放器接口、不运行网站脚本、不安装提取器或访问账号凭据。

自动短片仍只使用已实测能下载和采样的 NOAA / NASA；YouTube 此阶段仅手动公开阅读，不把只读简介升级为自动视频推荐。按维护者要求，不再继续研究 B站接入，B站/抖音保留原有手动入口。失败后六小时不自动反复撞同一平台。未找到条目、登录或验证墙、浏览器失败都会真实记录，不伪装成成功浏览。自主平台阅读失败时回到其他可验证公开来源，不新增每日探索额度。

B站优先匿名获取公开标题与简介；当前实测接口可用，但不保证网站长期保持同一实现。其他情况使用现有无网络容器浏览器和公网 HTTPS broker，不访问个人浏览器。抖音可尝试读取官方公开页文字，再尝试隔离页面；遇到登录/验证要求即停止，不绕过。短片模式最多检查三个候选，最多实际分析一个条目；普通模式选一个条目，没有点赞、评论、关注、投稿或私信代码路径。

默认是公开标题、简介、可见文案阅读。开启 `/watch on` 后，B站可尝试 [短片采样](watching.md)。两种模式都不是完整逐帧观看。 报告和活动记录明确这一点，作者文案也不是已独立核实的事实。用户直接提供的短视频采样能力是另一条路径。七天过期的隔离截图保存在私人 var 下，登录/验证页面不作为内容总结。

本机实际检查：B站公开条目成功读到标题和89字简介；所测抖音精选页未能完成匿名隔离渲染，已标为不可用，没有伪造内容。单元检查使用明确标记的元数据夹具和失败路径；不声称当前所有抖音内容都可读。网络情况和页面变化可能影响匿名可达性。

开启 `/watch on` 后，相关科学兴趣也可匿名查询 NASA 官方视频目录，或使用 `/platform nasa 宇宙`、`/platform nasa https://images.nasa.gov/details/条目编号`。NASA 使用官方低清视频文件，与 B站/抖音的可达性分别记录，遵守相同每日预算和冷却。见 [短片采样与验证](watching.md)。

2026-11-12 本机真实匿名读取一条 YouTube 公开页，取得标题、作者及简介；没有模型调用或微信发送。另一个隔离提取器原型在播放器接口遇到登录要求并停止，字幕请求没有返回内容；该原型只保存在私人测试目录，未打包进应用。故尚未实现 YouTube 自动看视频、听音轨或基于实际画面的主动推荐。
