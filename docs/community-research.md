# 社区大肥鱼设计研究

核查日期：2026-11-05。以下是对公开项目描述的设计研究，不是对其全部功能的独立实测，也不代表 DeepSeek 官方承诺。这里只借鉴设计原则，不复制角色素材、人设卡或项目代码。

| 一手来源 | 值得借鉴的设计 | 本项目的实现选择 |
| --- | --- | --- |
| [dsh-lan-memory](https://github.com/kiefeng/dsh-lan-memory) | 分开明确记忆与自动整理结果，按需召回，并保留删除标记 | SQLite FTS5 + 中文二元词、BM25；事实、经验和活动分开；整理经验须确认；删除标记只保存规范化内容哈希 |
| [dsh-aurabot-qq](https://github.com/aureth-labs/dsh-aurabot-qq) | 将人格、记忆、主动性等能力拆成可控模块，并把真实行动写成经历 | 保持官方微信渠道；兴趣研究明确启用、每日最多一次；只把成功任务与真实聊天保存为活动，不自动进行社交写操作 |
| [dsh-dafeiyu-dot](https://github.com/wz20/dsh-dafeiyu-dot) | 围绕角色、声音、记忆组织陪伴体验 | 当前先把相处连续性和可靠性做好；多媒体与视觉形象另行设计，不引入缺乏授权的素材 |

“有完整的一生”的可实现含义：身份与性格能够延续，经历有真实来源，能形成待确认的经验，迁移时能保留记忆，自主行为可以查看、暂停和撤销。不会靠编造活动或制造依赖感来营造“活着”的假象。

本轮优先交付：中文话题召回、常驻记忆、活动时间线、待确认经验、按兴趣进行的限额探索。普通记忆查询不调用模型，避免记忆增加就自动增加大量后台消耗。
