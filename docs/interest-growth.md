# 新兴趣与当天记录

`/growth on|off` 控制新兴趣扩展，默认关闭，不自动开启探索计划。开启后，累计至少三次真实内容判断，才在成功推荐的探索内尝试提出新方向；每七天最多一次额外 Codex 调用、最多新增一个兴趣，自动最多八个，留出手动添加至十个的空间。达到任务时限前会跳过这个可选阶段。没有独立常驻循环。

提出方向只带现有兴趣名称、近期排除名称和本次实际读取的公开来源片段，不读取聊天原话、综合报告或私人推荐理由。模型可以不提出新方向。结果仅是兴趣文本与来源记录，不是个人事实、感情或新权限；不生成代码或执行计划。非 Codex 提供方不会隐式切换到 Codex。

`/uninterest 编号` 记录排除名称；程序按规范化名称阻止自动恢复，并提示模型避免同义方向。明确再次 `/interest 主题` 可恢复。关闭扩展或移除父兴趣期间产生的结果不加入；清空聊天也不会让旧在途提案重新写入。关闭扩展不删除已有兴趣，手动决定仍优先。

`/day` 查看香港时间当天、清空背景之后的真实探索。完成记录、实际启动但失败的随机任务、仍在排队的工作和渠道接受的通知分别标注。渠道接受不证明送达或已读；读目录、读正文、短片采样也不能混为完整观看。聊天可以自然使用这些记录回答“今天都干嘛了”，没有记录不编造全天经历。

真实模型测试使用独立临时数据库与人工历史记录，实际读取 NOAA 白鲸公开网页，提出“声音与声呐定位原理”，并根据测试当天记录回答；没有在本次测试播放视频、发送微信或写入个人记忆。原始回执在根私人 var，不能当成生产鱼已经发生过的经历。来源隔离、每周上限、排除名称、在途关闭/清空、数量限制和跨日记录有独立行为检查。
