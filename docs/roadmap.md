# 从本地伙伴到微信伙伴

原提案采用 TypeScript + OpenClaw；本机无 Node.js，v0.1 用 Python 标准库交付本地相处闭环，避免在未验证渠道上声称交付。原始 proposal 不改动。

接下来仍需完成：

1. 安装固定版本 Node/OpenClaw，锁定腾讯插件版本与 commit。
2. 由账号本人微信扫码，验证稳定 sender_id、单用户鉴权、20 次收发和后台投递接口。
3. 验证立即、两分钟、一小时和跨日发送；记录 accepted、waiting_context、delivery_unknown，不保证微信无限推送。
4. 通过公开插件 API 对接本地任务；实现入站消息幂等、出站恢复、消息窗口处理后才称为微信 MVP。
5. 研究需要联网与来源核验；编程需要容器隔离、精确审批和进程终止机制。当前文本草稿不代替研究或编程能力。
6. 增加长期记忆检索、导出、按范围遗忘、数据库版本迁移和恢复演练，然后考虑常驻服务。

不复制社区人设卡或图片；可以由用户调整本项目原创人格。
