# 后续路线

## 当前范围（2026-11-13 更新）

大肥鱼以微信里的陪伴、记忆、探索和日常互动为核心。按维护者最新要求，不开发桌面形象、桌宠或动画界面；编程不是使用目标，保留现有小型 Python 隔离工具即可，不再规划 Node.js、TypeScript、多语言工程或复杂依赖安装。

已合并图片理解、离线语音转写与语音附件、公开网页浏览、兴趣笔记和白天随机探索。实际验证范围与限制以 verification.md 及各功能文档为准；原始 proposal 是早期构想，涉及桌面形象与复杂编程的内容不再属于当前开发范围。

生活助理新增明确个人待办：本机持久化、完成/恢复/删除、分页、未完成项去重与明确中文指令；与后台任务分开，不自动提醒，不从普通聊天推断待办。模型只能查询清单，不能替用户勾选完成。后续优先扩展日常实用能力，保留陪伴与自主探索的节制。

提醒新增按实际触发时间排序的列表，以及对尚未执行提醒的明确改期；不再仅依赖近期任务创建顺序查看提醒。已开始或结束的任务不能改期，离线仍不能保证准时执行；模糊的相对时间改期尚未实现。

## 后续优先级

1. 按维护者最新决定，不再研究 B站接入；优先扩展到 YouTube 这类题材广泛的平台。YouTube 已接入手动搜索与公开简介阅读，匿名播放器实测要求登录、字幕未取得，尚不能声称实际观看或自动视频推荐。自主短片暂仍使用已实测可用的 NOAA（海洋动物）和 NASA（宇宙科学）；继续寻找无需登录且有实际内容证据的广泛来源，不能把简介阅读或本机队列当作视频观看或微信送达。
2. 提高正常使用期间的稳定性：独立版本部署与回滚已实测；继续微信连续往返与跨日观察，长期在线、登录自启和常开设备部署已按维护者最新决定暂停，不要求 Mac 长期接电开盖。
3. 有选择的分享、相关旧话衔接及实际推荐记录已实现，仍需长期使用观察；继续提升陪伴体验：记忆检索、按范围遗忘、来源质量、长报告分段，以及自然、有节制的主动分享。
4. 补齐图片、语音和浏览器的真实微信端使用验证，持续维护备份恢复与安全更新。

随机探索遵守白天窗口、每日上限与额度停止线。它可以逐渐形成稳定性格与共同历史，不能声称具备已证实的人类意识或编造经历。

兴趣连续性：随机探索已加入有来源的兴趣线；成功发现的「下次想知道」可作为后续开放问题，适度换题，最多连续三层后重新分支。`/threads` 查看；不是用户事实，也不代表后续研究已执行。

关系连续性：带日期的真实用户原话与相关任务状态进入精简上下文，不自动推断身份或性格；自然查询任务时提供简短实际进展。明确记忆仍需用户授权，清空和遗忘仍生效。

表达方式按维护者最新选择使用普通 Unicode emoji；固定图片表情 PR29 已撤回，不接表情商店动图。公开内容扩展支持有界 RSS/Atom 目录和未读文章，仍不登录或对外评论。

长期在线暂不设计；Linux 主机方案 PR32 仅保存，未合并或部署。当前仅维护 Mac 正常运行期间的聊天服务。
