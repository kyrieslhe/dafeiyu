# 提醒清单与改期

`/reminders` 或直接说“看看我的提醒”，按**实际触发时间**查看尚未处理和正在处理的提醒，默认每页10条；`/reminders 2` 读第二页。显示香港时间、状态和真实编号，已到期但尚未处理会明确标注。已结束事项仍可通过 `/tasks` 或 `/result 编号` 检查，提醒清单不把结束状态当成消息已送达。

已有提醒尚未开始时，可以直接发文字改期：

```text
修改提醒 提醒编号 到 2026-12-01T09:00
/reschedule 提醒编号 2026-12-01T09:00:00+08:00
```

编号使用创建提醒时返回的12位编号，不是个人待办的数字编号。时间须在未来；未附时区按香港时间，有时区则转换显示。只修改同一提醒的到期时间，不新增重复任务、修改正文或重置状态；正在处理、已经结束及其他类型任务均拒绝改期。若后台先领走提醒，改期会明确失败，不冒充成功。

明确查询与改期格式直接在本机执行，不调用模型。其他自然表达可由聊天模型调用只读提醒查询；模型不能改期，也不能用一段“改好了”的回复替代真实更新。语音可查列表，但改期需要文字确认。取消已有提醒仍用 `/cancel 编号`。

提醒依赖当前电脑运行及渠道可用，休眠、离线时不能准时执行；这里不新增常开、自启、付费接口或模型回退。未解决的自然语义如“把刚才喝水那个推迟到明天”不能自动定位并改期，需明确编号及时间。
