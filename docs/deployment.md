# 独立代码版本与回滚

服务从忽略目录 `var/releases/<commit>` 的独立代码快照运行，不再直接加载开发目录里的 Python 和微信桥接代码。快照只来自 Git 已提交内容，准备时要求 HEAD 与本机 origin/main 一致且已跟踪文件干净；部署前先 fetch 并确认保护分支的检查通过。

```sh
git pull --ff-only
python3 scripts/deploy.py prepare
python3 scripts/deploy.py activate 完整提交编号
python3 scripts/deploy.py status
```

准备操作不影响服务；启用操作会短暂重启网关和 worker。有运行中的聊天或任务、或者服务被明确暂停时拒绝切换。服务锁防止监管进程同时重启；切换前持有数据库写锁检查空闲，停止旧服务后释放锁。启动后检查进程、HTTP 与微信渠道健康，失败时尝试恢复原代码位置和配置；失败后仍应检查服务状态。

每次启动校验快照中已记录代码文件的 SHA256。文件变动时拒绝启动，不退回开发目录。快照通过一个 `var` 链接使用原私人数据目录：没有复制聊天、数据库、微信或 Codex 登录凭据。配置仅在原文件更新插件代码路径；日志不输出配置或凭据。快照并非对拥有本机文件权限的用户的安全隔离。

```sh
python3 scripts/deploy.py rollback
```

回滚到上一份独立代码版本；第一次从开发目录迁移时没有上一份独立版本。也可明确 activate 已准备的旧提交。**仅回滚代码，不回滚数据库、模型、npm 运行时或已经发出的消息**。涉及不兼容数据库迁移或运行时变更时，须先验证兼容性和加密备份，不能直接依赖代码回滚。暂不自动删除旧快照。

当前会话监管仍由原目录启动，按版本收据启动网关和 worker；修改监管器本身仍需单独重启。升级后的媒体解码器等可选运行时若版本校验不符，需按各安装文档重建。此功能不解决 macOS 登录自启权限，也不保证合盖、关机或断网期间在线。
