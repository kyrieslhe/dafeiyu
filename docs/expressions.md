# 聊天里的原创表情

基于仓库自绘 MIT 小鲸鱼 SVG 派生四种表情：开心、好奇、休息、加油。公开 PNG 由原生矢量文件导出，不使用社区角色图、用户照片或远程图片；SVG 源文件与可选 macOS 导出脚本一并保留。不是桌宠。

模型只能选择四个固定名称，不能传入文件路径或 URL。应用复制到私人临时附件目录；绑定文字聊天的第一条回复可携带一张图片，文字独立可读。普通自动表达最多每天三张，至少间隔十五分钟；仅接口接受后计数，不把接受当已读。`/expressions off` 关闭，`/expressions on` 恢复。过期图片同临时语音保留七天。

以 PNG 图片附件发送，不声称是微信原生收藏表情。发送路径使用现有渠道媒体接口；本机固定图生成和模拟 runner 的收发链路已检查，微信实际图片呈现仍待使用验证。正常研究、提醒等任务优先，不为表情吞掉用户请求。离线语音与 WAV 附件功能继续保留，本项不新增付费图像或语音 API。
