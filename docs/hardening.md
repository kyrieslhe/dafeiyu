# 边界与本机部署复核

日期：2026-11-05。

- 来源抓取放入受限时长的独立 Python 进程，整个 DNS/TLS/正文读取最多 15 秒，结束后回收。来源仍要求 HTTPS，逐次重定向重新验证 DNS 并固定已检查 IP。
- 显式拒绝组播、地址转换/隧道、IPv4-mapped IPv6 及特殊用途地址，避免不同 Python 版本地址分类差异。优先使用已检查的原生 IPv4。参考 [Python ipaddress 文档](https://docs.python.org/3/library/ipaddress.html)。
- 来源记录标记正文是否截断，不能把片段当作完整页面。真实 Python 官方页面抓取通过；私网、重定向和整体超时边界另有自动测试。
- 候选只能修改受支持的 UTF-8 文本类型；拒绝二进制、未纳入快照的现有文件，以及大小写、Unicode 等价和非规范路径。修复了旧逻辑可能把未收录的二进制目标当作“新文件”的问题。
- 本机 LaunchAgent 安装曾被 macOS 的 Documents 文件访问权限拒绝；已经撤销启动项并恢复可用的手动后台服务，没有修改系统隐私授权。安装器现增加真实进程就绪检查与自动撤销恢复，不再把“注册成功”当作“已经运行”。

当前服务可以在本次用户登录期间继续运行；开机/下次登录自动启动仍需要在本机授予相应文件访问或迁移项目位置后验证。源码和模板测试不替代这个真实 OS 权限闸门。
