# 有选择的主动分享和兴趣连续性

自主探索先抓取真实来源，再在原有的一次 Codex 综合调用里同时生成短文、是否推荐和理由。可以不推荐：信息不足、重复、空泛或只有文案的发现保留私人记录，不生成新通知；后台探索失败和超时也安静记录。用户手动交代的任务仍会返回结果或失败。不是所有研究都会自动推送。

最终表达可参考三天内、词语匹配相关的最多两条带日期用户原话，以及最近实际探索选择。匹配是有限词语重合，不是可靠的语义理解；不相关就不提，不推断用户性格、当前情绪或长期偏好。原话经过凭据过滤，最多200字符；不新增个人记忆。

公开搜索仅使用已配置的兴趣主题，不附带聊天原话、旧分享全文或续篇的私人背景。私人背景只进入禁用搜索和执行工具的最后综合调用。旧摘要即便引用过聊天，也不会在下一轮重新成为搜索词。代价是搜索较宽泛，后续问题主要在综合阶段衔接；不能保证每轮都找到精确的新答案。

`/taste` 查看本鱼近30天实际探索的推荐次数与理由。下一次选题给予过去推荐较多的主题小幅权重（最多3比1），仍有25%均匀选题机会，保留原有避开上一主题与深度限制。这是可改变的内容选择，不是用户画像、平台点赞或情绪，也不证明消息已送达。

`/clear` 与明确记忆遗忘会清空这些衍生选择、兴趣摘要，取消旧自动探索，并抑制尚未投递的旧自动发现。在途结果在提交前再次核对清空代数，不能恢复旧背景。已经进入发送进程的消息无法召回。明确记忆仍按原有命令分别处理；历史任务报告、备份和原始平台文件仍需单独管理，不宣称安全擦除所有历史。

随机频率、每日四次探索、两条分享、额度低于10%暂停、免打扰和微信会话限制均沿用。没有为了判断是否分享额外增加生产模型调用。

验证：单元测试覆盖真假判断、私人原话不进入搜索、后续摘要不泄漏到搜索、清空前后并发提交、视频判断清空、推荐权重、失败安静记录及手动失败保留。真实 NASA 来源抓取加真实 Codex 综合/结构判断已验证，使用临时数据库里的人工测试聊天，无真实用户原话、无微信发送；该手动验证分两次调用，生产流程在一次综合中完成。实际长期拟人感和微信推送仍需日常观察。

## 分享后的接话

近期最多两条、24小时内被渠道接受的研究/探索/浏览/视频通知，会以原文片段和时间进入聊天背景。只使用与当前绑定身份对应、带投递关联的记录；旧版本没有这种关联的历史通知不会猜测补齐。待发送、失败、超时、未知状态不会冒充已分享。渠道接受仍不证明送达或已读，也不是重新观看视频。用户说「刚发的那个」时可据此接话，不能据此编造新画面。清空/遗忘删除此背景关联，在途发送无法召回，旧内容不会因此重新进入聊天背景。

明确到点提醒优先于普通分享，可以越过免打扰中的分享及正在排队/处理的普通聊天。全局暂停、渠道上下文限制和已有发送间隔仍生效；不承诺系统休眠时提醒。实际完成发送请求的时间用于间隔计算。
