# 自主刷视频与分享

`/watch on` 开启，`/watch off` 关闭，`/watch` 查看开关和近期判断。默认关闭，不会开启原本关闭的 `/life`；需已有白天探索计划才会自主发现。`/platforms off` 仍关闭自主平台尝试。

流程：沿着自己的兴趣线搜索最多三个 B站公开条目 → 匿名获取单段、免费、非预览 MP4 → 下载最多20MB、两分钟的短片 → 现有无网络容器抽取四帧、最多60秒音轨 → 本机离线转写 → 一次 Codex 图像推理同时输出观察、推荐与理由。失败候选使用独立输出目录；原始下载在分析结束或失败后删除。搜索和理解使用现有 Codex 额度，无付费备用模型。

这里只是采样，不是连续完整观看。标题和简介是作者说法，不能据此编造画面或声音。「喜欢」表示本次模型依据内容、兴趣目标作出的可解释推荐选择，不是平台点赞，也不代表人类情感；不根据它推断用户性格或新增个人记忆。

30天内已分析的同一视频不重复自动采样。判断不推荐时保留私人记录，不发通知；只读简介的探索也不推送为视频推荐。喜欢的短片才进入已有投递队列，保留原视频链接，并遵守两条新分享/天、四次探索/天、白天随机时段、聊天避让、免打扰、暂停和额度保护。没有另起高频刷视频循环。不点赞、关注、评论或登录。

只允许 B站官方域名返回的 HTTPS bilivideo.com 子域播放资源，逐跳验证公网地址及 TLS；不使用第三方解析站、Cookie、用户会话或绕过验证。此公开接口是当前观察到的行为，不是平台承诺稳定的开放 API。播放地址仅经私人子进程输入传递，不进入提示词或分享。拒绝、超时、超范围时退回标题/简介，并冷却平台六小时。抖音仍只尝试匿名公开文字，没有声称能播放其视频。

## 验证范围

2026-11-06：真实 B站公开元数据与播放接口返回一条约68秒、1.7MB的短片信息，但实际 CDN GET 返回 HTTP 567，下载被拒绝，未取得该片画面或音轨。因此尚未验证 B站视频从下载到微信分享的完整成功链路。

实际无网络容器测试验证原创三秒视频的四帧采样及 AAC 音轨提取；单元测试验证尺寸/时长/付费/预览限制、下载完整性和失败清理、判断结构、重复跳过与不推荐不通知。模型实测和真实平台可达性另存私人记录。CI 不访问真实模型、不发送微信消息。
