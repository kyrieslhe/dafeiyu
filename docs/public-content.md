# 公开内容来源

自主探索可按兴趣读取 RSS/Atom 目录，从未读条目抓取正文；取得正文后直接综合，否则再搜索其他来源。新安装默认目录为 NOAA 海洋知识、NASA 新闻、GitHub Blog 和 arXiv AI 的公开查询（最多五条）；可 `/feeds` 查看、`/feeds on|off` 切换、`/feeds add 主题 HTTPS地址` 添加、`/feeds remove 编号` 删除，最多十个。它们是内容来源，不是你的个人偏好或已阅读证明。

每轮最多一个目录、两篇未读候选，取得一篇正文后停止；包括失败在内最多四次来源读取尝试。未读记录只在任务成功后保存，30天过期。不增加每日探索或分享上限。目录不能当作文章全文；只有目录时不调用综合模型、不推荐。已有未读正文时省去额外搜索模型调用；需要搜索时仍不携带私人聊天摘要。条目发布日期保留，未读不等于近期发布。来源恢复与实际验证见 [海洋来源](marine-discovery.md)。

沿用公开 HTTPS、DNS固定到公网、请求整体时限、400KB下载上限；XML 禁止实际 DTD/实体声明，普通 CDATA 里的文档示例不执行。订阅地址不含账号密码或认证参数，链接再次经过同样公网校验。没有登录网站、读取 Cookie、评论或投稿功能。微信表情商店接入已按维护者决定放弃，表达改为普通 Unicode emoji，外观由接收设备决定。

已实际抓取并解析 NASA（10条）、GitHub Blog（10条）、arXiv公开查询（5条），没有调用模型或发送平台消息。原始 arXiv 大目录超过上限，改为官方公开查询的小批结果。正文与模型总结的组合由夹具检查覆盖；不声称完成所有平台或任意视频的阅读。

来源说明：[NASA RSS](https://www.nasa.gov/rss-feeds/)、[arXiv 官方 RSS 文档](https://github.com/arXiv/arxiv-docs/blob/develop/source/help/rss.md)。
