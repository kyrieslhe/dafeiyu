# Security

Report vulnerabilities using this repository's private security advisory flow, rather than posting credentials or private conversations in public issues. Supported release: 0.2.x and newer maintained releases.

This is a single-user local companion. The gateway listens on loopback with authentication. Only the locally bound WeChat account and stable peer ID can access memory and tasks. Do not expose its port or data directory publicly.

Generated code executes only inside a restricted Docker container. Host-side candidate application requires an expiring, exact digest approval. Model instructions alone are not an isolation mechanism. The current code runner supports bounded Python projects without external dependencies.

`var/`, `.env`, authentication files, databases, logs, backups and reports must remain private. The code is open source; your companion's memory and messages are not. The model provider receives the context needed for requests. Do not put secrets in conversational memory or candidate projects.

Research URLs and source text are untrusted. Retrieval rejects private addresses and pins TLS connections after DNS validation. A fetched page may still contain incorrect information or prompt injection; sources do not grant execution privileges.

Use `python3 scripts/services.py stop` to stop this project's services. Revoke channel/provider authorization separately using their official tools if a credential is compromised.
