# Working on Dafeiyu

- Use feature branches and pull requests. Do not bypass main protection or required checks.
- Keep credentials, QR codes, personal identities, messages, databases, reports and recovery keys under ignored private storage. Run the history privacy audit before publishing.
- Use official Codex authentication. Do not copy tokens, scrape browser sessions, add implicit paid fallbacks, purchase credits or consume reset entitlements without explicit authorization.
- The maintainer requests an account quota guard: when any applicable readable quota window has less than 10% remaining, stop starting new work, commit or otherwise preserve changes, and write a private checkpoint under var/ before waiting for recovery. Unknown limits are not zero or unlimited. Prefer the desktop usage-limits tool when available.
- Distinguish mock tests, actual container/cryptography checks and real platform evidence. Never claim a successful process registration proves OS startup or message delivery.
- Generated project code runs only in the isolated container. Applying candidates requires exact, unexpired owner approval.
- Test the behavior changed. Do not call real models or send platform messages in ordinary CI.
